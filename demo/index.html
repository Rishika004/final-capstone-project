What this demo is, and is not

Every number in the paper comes from LibriSpeech — clean studio read speech, 29 speakers — with a verifier threshold calibrated on that corpus. A laptop microphone in a room is out of domain. A weak live run is a weak live run on unseen audio, not a result and not a refutation. The paper's own figures are shown beside the live ones for exactly that reason.
